# CircuitBreakersTKM.github.io

Veřejný web týmu **CircuitBreakers** z Litoměřic.

- statický web bez build kroku
- nasazení přes GitHub Pages
- responzivní layout
- scroll storytelling + canvas efekt
- respektuje `prefers-reduced-motion`
- veřejná fakta jsou odkázaná na RobUL, UJEP a ICUK

## Lokální spuštění

```bash
python -m http.server 8000
```

Pak otevřít `http://localhost:8000`.
